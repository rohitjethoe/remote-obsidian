## 1: Propositional Logic
---
### 1.2: Equivalence in Propositional Logic using Truth Tables
---
In English we would write:
$$
\text{Are } \neg p \lor q \text{ and } p \rightarrow q \text { equivalent?}
$$
In Logic we use the equivalence symbol and put a question mark on top of it:
$$
\neg p \lor q \stackrel{?}{\equiv} p \rightarrow q
$$
- Because we are not sure yet if they are equivalent.
- That is the question we’re asking, what now?

For two proposition to be equivalent, we need them to be true for the same cases, i.e. for every combination of truth values both propositions need to have the same value.

| $p$ | $q$ | $\neg p \lor q$ | $p \rightarrow q$ |
| --- | --- | --------------- | ----------------- |
| 0   | 0   | ==1==           | ==1==             |
| 0   | 1   | ==1==           | ==1==             |
| 1   | 0   | ==0==           | ==0==             |
| 1   | 1   | ==1==           | ==1==             |
The truth tables are identical, so $\neg p \lor q \equiv p \rightarrow q$
