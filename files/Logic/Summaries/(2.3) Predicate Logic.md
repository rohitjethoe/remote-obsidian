## Ch. 2.4: Predicate Logic
---
In propositional logic:
- We can let $p$ stand for **"Roses are red"** and $q$ for **"Violets are blue"**
- Then $p \land q$ stands for **"Roses are red and violets are blue"**
- But we lose a lot in the translation into logic.

Since propositional logic only deals with truth values, we can't do anything with $p$ and $q$ that has anything to do with roses, violets or color.

To apply logic to such things, we need **predicates** or **predicate logic**.

**Predicate calculus** deals with manipulating and reasoning with predicates.

### Ch. 2.4.1 Predicates
---
**A predicate** = a kind of incomplete proposition, which becomes a proposition when it is applied to some entity (or to several entities).

In the proposition "the rose is red", the predicate is "— is red". 
- The slot is filled by "the rose". 
- Other entities work as well: "the barn is red", "the wine is red"
- These are different propositions using the same predicate and can have different truth values.

If $P$ is a predicate and $a$ is an entity, then $P(a)$ stands for the proposition that is formed when $P$ is applied to $a$

Let $P$ stand for the predicate "is red", and $a$ stand for "the rose", then $P(a)$ stands for the proposition "the rose is red".

If $M$ stands for the predicate "is mortal", and $s$ stands for "Socrates", then $M(s)$ is the proposition "Socrates is mortal".

Generally, it doesn't make sense to apply a given predicate to every possible entity
- E.g. "is mortal" makes sense when applied to entities in the category of living things.
- This category is called **the domain of discourse**.

**Domain of Discourse** = the category to which a predicate can be applied.

In Set Theory; we would say that a domain of discourse is a set, $U$, and a predicate is a function from $U$ to the set of truth values.

**Definition 2.7:** 
- A **one-place predicate** associates a proposition with each entity in some collection of entities
- This collection is called **domain of discourse** for the predicate
- If $P$ is a predicate and $a$ is an entity in the domain of discourse for $P$, then $P(a)$ denotes the proposition that is associated with $a$ by $P$
- We say that $P(a)$ is the result of **applying** $P$ to $a$

We can extend this to predicates that can be applied to two or more entities.
- "John loves Mary", where "— loves —" is a **two-place predicate**
- "$a$ gave $b$ to $c$" is a **three-place predicate**
- "$a$ bought $b$ from $c$ for $d$ euros" is a **four-place predicate**
- Not every predicate has to correspond to an English sentence.

If $Q$ is a two-place predicate, then $Q(a, b)$ denotes the proposition that is obtained when $Q$ is applied to the entities $a$ and $b$.
- Each of the 'slots' can have their own domain of discourse.

When predicates are applied to entities, they become propositions:
- All operators of propositional logic can be applied to them

Let $R$ be the predicate "is red" and $L$ be the two-place predicate "loves". Then we can form compound propositions such as:
$$
\begin{array}{ll} 
R(a) \land R(b) & a \text{ is red and } b \text{ is red}
\newline \neg R(a) & a \text{ is not red}
\newline L(j, m) \land \neg L(m, j) & j \text{ loves } m, \text{ and } m \text{ does not love } j
\newline L(j, m) \rightarrow L(b, m) & \text{if } j \text{ loves } m, \text{ then } b \text{ loves } m
\newline R(a) \leftrightarrow L(j, j) & a \text{ is red if and only if } j \text{ loves } j
\end{array}
$$

### Ch. 2.4.2: Quantifiers
****
Consider the proposition “Roses are red.” 
- This proposition does not saying something about a particular entity
- It really says that **all** roses are red
- Predicates can only be applied to individual entities

**A quantifier** = words like *all*, *no*, *some* and *every*

We write $\forall x (P(x))$ when expressing that $P$ is true **for every** entity in the domain of discourse
- $\forall$ is usually read as “for all”
- $\forall x (P(x))$ = “for all $x$, $P(x)$”

An example of the **universal quantifier**:
- If $R$ is the predicate “is red” and the domain of discourse consists of all roses 
- Then $\forall x R(x)$ is the proposition “all roses are red”.

We write $\exists x (P(x))$ when expressing that $P$ is true **for some** entities in the domain of discourse.
- $\exists$ is usually read as “there exists” or “there is at least one”
- $\exists x (P(x))$ is the proposition “there exists an $x$ such that $P$

An example of the **existential quantifier**:
- $\forall x R(x)$ is the proposition "There is a red rose" or "At least one rose is red"

**Definition 2.8**: 
- Suppose $P$ is a one-place predicate. 
- Then $\forall x (P (x))$ is a proposition, which is true iff $P(a)$ is true for every entity $a$ in the domain of discourse for $P$
- And $\exists x(P(x))$ is a proposition which is true if and only if there is at least one entity, $a$ in the domain of discourse for $P$ for which $P(a)$ is true.
- The $\forall$ symbol is called **universal quantifier** and $\exists$ is called **existential quantifier**.

**Entity variable** =  the '$x$' in $\forall x (P(x))$ and $\exists x (P(x))$ 
- A plain $P(x)$ without quantifier $\forall x$ or $\exists x$ is not a proposition

$P(x)$ becomes a proposition if some entity $a$ is substituted for $x$, giving $P(a)$
- $P(x)$ would stand for something like '$x$ is red' which isn't really a statement
- It becomes a statement when $x$ is replaced by some particular entity such as 'the rose'

**Open statement** = an expression that contains 1 or more entity variables, which becomes a proposition when entities are substituted for the variables
- An open statement has open 'slots' that need to be filled in 

If $L$ is a two-place predicate and $x$ and $y$ are variables. Then $L(x, y)$ is an open statement containing two variables
- The variables in an open statement are called **free variables**

An open statement that contains $x$ as free variable can be quantified with $\forall x$ or $\exists x$. The variable $x$ is then said to be **bound**.
- $x$ is free in $P(x)$ and is bound in $\forall x (P(x))$
- $\forall y (L(x, y))$ is still an open statement since it contains $x$ as a free variable
- If all variables are bound in these expressions, they become propositions

### Ch. 2.4.3: Operators
---
In predicate logic, the operators and laws of Boolean algebra still apply.

If $P$ and $Q$ are one-place predicates and $a$ is an entity in the domain of discourse 
- Then $P(a) \rightarrow Q(a)$ is a proposition
- It is logically equivalent to $\neg P(a) \lor Q(a)$

$P(x) \rightarrow Q(x)$ is an open statement and $\forall x (P(x) \rightarrow Q(x))$ is a proposition
- So are $P(a) \land (\exists x Q(x))$ and $(\forall x P(x) \rightarrow \exists x P(x))$

If the domain of discourse consists of roses, $\forall x Red(x)$ stands for "Roses are red". 
- It makes more sense if the domain of discourse is larger (for example all flowers)

Then $\forall x (Rose(x) \rightarrow Red(x))$ translates to "All flowers which are roses are red".hel
