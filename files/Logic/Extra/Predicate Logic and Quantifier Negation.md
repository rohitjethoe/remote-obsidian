## Predicate Logic and Quantifiers
---
### We want to talk about variables
---
**Variables**: 
- $G(x, y) = x \text{ is greater than } y$
- $G(2, 1) = 2 \text{ is greater than } 1 = \mathbb{T}$
- $G(3,6) = 3 \text{ is greater than } 6 = \mathbb{F}$

Closed formulas have truth values and open formulas don’t.
- Open formulas are not called statements

### We also want to introduce quantifiers
---
**Quantifiers**:
- $\forall x P(x) : \text{ “For all } x, x \text{ is P”}$
- $\exists x P(x) : \text{ “For some } x, x \text{ is } P\text{“}$

$\forall x$ = Universal Quantifier “for all, every, each $x$”
$\exists x$ = Existential Quantifier “there exists an $x$”

### We use this notation everywhere in mathematics
---
- For every real number $n$, there exists a real number $m$ such that $m^2 = n$
$$\forall n \in \mathbb{R}, \exists m \in \mathbb{R} : m^2 = n $$
- Given two rationals $x$ and $y$, $\sqrt{ab}$ will also be rational
