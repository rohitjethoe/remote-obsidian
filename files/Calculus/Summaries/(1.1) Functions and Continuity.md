## 1.1: Functions and Continuity
---
A function $f : A \rightarrow B$
- Has a domain $A$ and co-domain $B$ a subset of real numbers
- The **range** of $f$ = the set of real numbers that are reached by $f$

The **product** of two function $f(x)$ and $g(x)$ is again a function
$$h(x) = f(x)g(x)$$
The **composition** of two functions $f(x)$ and $g(x)$ is again a function
$$h(x) = (f \circ g)(x) = f(g(x))$$

**Definition:**
- Suppose $f$ i s a function with domain $D$ and range $R$
- A function $g$ is the **inverse** of $f$ (on $R$)
- If for all $x$ in $D$ and $y$ in $R$ the following holds:
$$f(x) = y \Leftrightarrow x = g(y)$$

A function $f$ is invertible precisely if it is **one-to-one**. That is:
$$f(x_1) \neq f(x_2) \text{ for all } x_1 \neq x_2$$

**How to find the inverse of a function?**
The inverse of a one-to-one function can be obtained as follows:
1. Start with $y = f(x)$
2. Solve this equation for $x$ (in terms of $y$)
3. Interchange the role of $x$ and $y$, then we have: $y = f^{-1}(x)$

**Definition of** $arcsin(x), arccos(x)$ and $arctan(x)$**:**
- $arcsin(x) = y \Leftrightarrow sin(y) = x \land - \dfrac{\pi}{2} \leq y \leq  \dfrac{\pi}{2}$
- $arccos(x) = y \Leftrightarrow cos(y) = x \land 0 \leq y \leq  \pi$
- $arctan(x) = y \Leftrightarrow tan(y) = x \land - \dfrac{\pi}{2} \leq y \leq  \dfrac{\pi}{2}$

## 1.5: Inverse Functions and Logarithms
---
### Inverse Functions
---
**Definition:**
A function $f$ is called a **one-to-one function** if it never takes on the same value twice; that is
$$
f(x_1) \neq f(x_2) \text{ whenever } x_1 \neq x_2
$$
- **Horizontal Line Test** = A function is one-to-one iff no horizontal line intersects its graph more than once

**Definition:**
- Let $f$ be a one-to-one function with domain $A$ and range $B$. 
- Then its **inverse function** $f^{-1}$ has domain $B$ and range $A$
- And is defined by $f^{-1}(y) = x \Leftrightarrow f(x) = y$ for any $y$ in $B$

Note that:
- This definition says that if $f$ maps $x$ into $y$, then $f^{-1}$ maps $y$ into $x$.
- If $f$ were not one-to-one, then $f^{-1}$ would not be uniquely defined

And also: 
$$
\begin{array}{ll} 
\text{domain of } f^{-1} = \text{range of } f
\newline \text{range of } f^{-1} = \text{domain of } f
\end{array}
$$

**How to find the Inverse Function of a one-to-one function?**
1. Write $y = f(x)$
2. Solve this equation for $x$ in terms of $y$ (if possible)
3. To express $f^{-1}$ as a function of $x$, interchange $x$ and $y$. Resulting in $y = f^{-1}(x)$

The graph of $f^{-1}$ is obtained by reflecting the graph of $f$ about the line $y = x$

### Logarithmic Functions
---
 **The exponential function** $f(x) = b^x$ 
 - If $b > 0$ and $b \neq 1$, is either **increasing** or **decreasing**.
 - It is **one-to-one** by the Horizontal Line Test
 - Therefore $b^x$ has an inverse function called the **logarithmic function with base $b$**
$$
 log_b(x) = y \Leftrightarrow b^y = x
$$
The cancellation equations become:
$$
\begin{array}{ll} 
log_b(b^x) = x \text{ for every } x \in \mathbb{R}
\newline b^{log_b(x)} = x \text{ for every } x > 0
\end{array}
$$
The logarithmic function $log_b$ 
- Has domain $(0, \infty)$ and range $\mathbb{R}$ 
- Its graph is the reflection of the graph of $y = b^x$ about the line $y = x$

**Laws of Logarithms**
If $x$ and $y$ are positive numbers, then:
1. $log_b(xy) = log_b(x) + log_b(y)$
2. $log_b(\dfrac{x}{y}) = log_b(x) - log_b(y)$
3. $log_b(x^r) = r \cdot log_b(x)$ where $r$ is any real number

### Natural Logarithms
---
The logarithm with base $e$ is called **natural logarithm**
$$
log_e(x) = ln(x)
$$
It's defining properties become:
- $ln(x) = y \Leftrightarrow e^y = x$
- $ln(e^x) = x$ where $x \in \mathbb{R}$
- $e^{ln(x)} = x$ where $x \gt 0$

A power of $x$ can be expressed in an equivalent exponential form (useful in the chapters to come): $$x^r = e^{ln(x^r)} = e^{r \cdot ln(x)}
 $$
**Change of Base Formula**: Logarithms with any base can be expressed in terms of the natural logarithm:
- for any positive number $b$ ($b \neq 1$)
- $log_b(x) = \dfrac{ln(x)}{ln(b)}$

**PROOF:**
1. Let $y = log_b(x)$
2. Then from (6), we have $b^y = x$
3. Taking natural logarithms of both sides gives $ln(b^y) = ln(x)$
4. We get $y \cdot ln(b) = ln(x)$. Therefore $y = \dfrac{ln(x)}{ln{b}}$

### Inverse Trigonometric Functions
---
**Inverse sine function** or the **arcsine function**:
- If we restrict the domain of $y = sin(x)$ to the interval $[-\pi / 2, \pi / 2]$, the function becomes one-to-one 
- All values in the range of $y = sin(x)$ are attained
- The inverse function of the restricted sine is denoted by $sin^{-1}$ or $arcsin$ 

Since the definition of an inverse functions says that
$$f^{-1}(x) = y \Leftrightarrow f(y) = x$$
We have
$$
sin^{-1}(x) = y \Leftrightarrow sin(y) = x \text{ and } -\dfrac{\pi}{2} \leq y \leq \dfrac{\pi}{2}
$$
The cancellation equations become:
$$
\begin{array}{ll} 
sin^{-1}(sin(x)) = x \text{ for } -\dfrac{\pi}{2} \leq x \leq \dfrac{\pi}{2}
\newline sin(sin^{-1}(x)) = x \text { for } -1 \leq x \leq 1
\end{array}
$$
The **restricted cosine function** is one-to-one:
- $f(x) = cos(x)$ with $0 \leq x \leq \pi$
- So it has an inverse function denoted by $cos^{-1}$ or $arccos$
$$
cos^{-1}(x) = y \Leftrightarrow cos(y) = x \text { and } 0 \leq y \leq \pi
$$
The cancellation equations become:
$$
\begin{array}{ll}
cos^{-1}(cos(x)) = x \text { for } 0 \leq x \leq \pi
\newline cos(cos^{-1}(x)) = x \text { for } -1 \leq x \leq 1
\end{array}
$$
The **restricted tangent function** is also one-to-one:
- $f(x) = tan(x)$ with $-\pi / 2 \leq x \leq \pi / 2$
- It's inverse function is denoted by $tan^{-1}$ or $arctan$
$$
tan^{-1}(x) = y \Leftrightarrow tan(y) = x \text { and } -\dfrac{\pi}{2} \leq y \leq \dfrac{\pi}{2}
$$
## 2.2: The Limit of a Function
---
### Finding Limits Numerically and Graphically
---
Let's investigate: 
$$f(x) = \dfrac{x-1}{x^2 -1}$$
- The closer $x$ is to 1, the closer $f(x)$ is to 0.5

We express this by saying "the limit of the function $f(x) = (x - 1)/(x^2 - 1)$ as $x$ approaches 1 is equal to 0.5"
$$
\lim_{x \to 1}\dfrac{x - 1}{x^2 - 1} = 0.5
$$
In general, we use:

**Intuitive Definition of a Limit**:
- Suppose $f(x)$ is defined when $x$ is near the number $a$. 
- i.e. $f$ is defined on some open interval that contains $a$, except possibly at $a$ itself
- We write $\lim_{x \to a} f(x) = L$ 
- "The limit of $f(x)$ as $x$ approaches $a$, equals $L$"
- If we can make the values of $f(x)$ arbitrarily close to $L$ (as close to $L$ as we like) by restricting $x$ to be sufficiently close to $a$ (on either side of $a$) but not equal to $a$ 

It says that values of $f(x)$ approaches $L$ as $x$ approaches $a$

An alternative notation for $\lim_{x \to a} f(x) = L$ is:
- $f(x) \to L$ as $x \to a$
- "$f(x)$ approaches $L$ as $x$ approaches $a$"

### One-Sided Limits
---
The Heaviside function $H$ is defined by:
$$
H(t) = 
\begin{cases}
0 \text{ if } t \lt 0 \\
1 \text{ if } t \geq 0
\end{cases}
$$
- This function is named after electrical engineer Oliver Heaviside (1850-1925)
- Describes an electric current that is switched on at time $t = 0$

The limit of $H(t)$ as $t$ approaches 0 does not exist. However: 
- As $t$ approaches 0 **from the left**, $H(t)$ approaches 0
- As $t$ approaches 0 **from the right**, $H(t)$ approaches 1

We indicate this situation symbolically by writing:
$$
\lim_{t \to 0^-} H(t) = 0 \text{ and } \lim_{t \to 0^+} H(t) = 1
$$

These are called **one-sided limits**
- $(t \to 0^-)$ considers values of $t$ that are less than 0
- $(t \to 0^+)$ considers values of $t$ that are greater than 0

**Intuitive Definition of One-Sided Limits**:
- We write $\lim_{x \to a^-} f(x) = L$
- The **left-hand limit** of $f(x)$ as $x$ approaches $a$ is equal to $L$
- If we can make values of $f(x)$ arbitrarily close to $L$ by restricting $x$ to be sufficiently close to $a$ with $x$ less than $a$ 

- We write $\lim_{x \to a^+} f(x) = L$
- The **right-hand limit** of $f(x)$ as $x$ approaches $a$ is equal to $L$
- If we can make values of $f(x)$ arbitrarily close to $L$ by restricting $x$ to be sufficiently close to $a$ with $x$ greater than $a$

The definition of one-sided limits differs from the definition of a limit only in that we require $x$ to be less than (or greater than) $a$. The following is true:
$$
\lim_{x \to a} f(x) = L \Leftrightarrow  \lim_{x \to a^-}f(x) = L \land \lim_{x \to a^+} f(x) = L
$$
### How can a limit fail to exist?
---
We've seen that a limit fails to exist at $a$ if the left- and right-hand limits are not equal

$f(x) = \sin(\pi / x)$ is $\text{undefined}$ at 0 
- Although $f(1/n) = \sin(n \pi) = 0$ for any integer $n$, 
- It is also true that $f(x) = 1$ for infinitely many values of $x$ (e.g. $\dfrac{2}{5}$ or $\dfrac{2}{101}$)
- $\sin(\pi / x)$ oscillates between 1 and -1 as $x$ approaches 0

Since the values of $f(x) = \sin(\pi / x)$ do not approach a fixed number as $x$ approaches 0
$$
\lim_{x \to 0}\sin(\pi / x) \text{ does not exist}
$$
